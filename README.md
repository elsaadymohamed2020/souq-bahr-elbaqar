# سوق بحر البقر الكبير — نموذج الموقع ولوحة التحكم (React + Vite)

منصة متكاملة مصممة خصيصاً كـ Demo احترافي لعرضه على إدارة **سوق بحر البقر الكبير** (بحر البقر والصالحية الجديدة، الشرقية).

---

## 🌟 مميزات المشروع

### 1. واجهة الزبائن (المتجر الإلكتروني):
- **تصميم فندقي عصري (Modern UI & Glassmorphism):** بألوان كحلي راقية (`#0B152B`) ولمسات ذهبية برتقالية (`#F59E0B`) مع خطوط عربية احترافية (`Cairo` للعناوين و`IBM Plex Sans Arabic` للقراءة).
- **إجابات سريعة للأسئلة المتكررة:** حل مشكلات التعليقات المكتشفة في ريلز فيسبوك (كروت: **بكام؟** / **فين المكان؟** / **لسه موجود؟**).
- **معرض المنتجات التفاعلي:** تصنيفات فورية (أجهزة منزلية، معدات صناعية، موبيليا وأبواب)، مع شارات الحالة (متاح، محجوز، اتباع)، وحساب تلقائي للخصومات والعروض السارية.
- **حجز مباشر بنقرة زر على الواتساب:** رابط واتساب مجهز مسبقاً بنص الرسالة وكود القطعة وسعرها المطلوب.
- **دليل الفروع وخرائط GPS:** روابط مباشرة لخرائط جوجل («وديني باللوكيشن») لفرعي بحر البقر والصالحية الجديدة.
- **حماية الاسم التجاري وتوثيق الأرقام:** قسم تحذير من الصفحات المزيفة مع إبراز أرقام التواصل الرسمية فقط.
- **حالة المعرض اللحظية:** حساب أوقات العمل في مصر (مفتوح حتى 5 مساءً / مغلق).

### 2. لوحة تحكم الإدارة (Admin Dashboard):
- **الرئيسية (Overview):** مؤشرات الأداء (KPIs)، تقرير الرد التلقائي الذكي على 64 تعليق واستفسار، ورسم بياني تفاعلي لمبيعات الأسبوع، ونسب قنوات التواصل.
- **صندوق الرسايل الموحد (Unified Inbox):** محاكاة استقبال رسايل واتساب وفيسبوك وإنستجرام مع ردود آلية و«ردود سريعة جاهزة».
- **إدارة المعروض والمنتجات:** تغيير حالة أي قطعة (متاح / محجوز / اتباع) وتنعكس فوراً في واجهة الزبائن.
- **لحظة الإبهار (Killer Demo Moment):** عند إضافة قطعة جديدة (مثل «موتور مية»)، يكتشف النظام فوراً وجود عملاء مسجلين في قائمة الانتظار في الـ CRM كانوا يطلبون موتور، ويقترح عليك إرسال رسالة واتساب لهم فوراً!
- **العروض الترويجية:** تفعيل وإيقاف الخصومات بضغطة زر مع محاكاة إرسال برودكاست للعملاء.
- **العملاء (CRM):** دليل العملاء المصنفين (جديد، مهتم، مستني قطعة، اشترى)، وسجل التعاملات والمشتريات.
- **الحسابات والمخزن (ERP):** حساب الأرباح، مبيعات كل فرع، وقيمة بضاعة المخزن بسعر التكلفة، وتسجيل الفواتير.
- **إعادة تعيين الديمو (Reset Demo):** إمكانية إعادة كل البيانات إلى حالتها الأولى بنقرة واحدة في أي وقت.

## 🚀 التشغيل محلياً

```bash
# تثبيت الاعتماديات
npm install

# تشغيل سيرفر التطوير المحلي
npm run dev
```

افتح المتصفح على: `http://localhost:5173`

## 🌐 الرفع على Vercel بنقرة واحدة

المشروع جاهز ومضبوط بملف `vercel.json` للرفع المباشر:

### الطريقة الأولى: عبر Vercel CLI (الأسرع خلال ثوانٍ):
```bash
npx vercel
```
اتبع التعليمات السريعة على الشاشة، وسيمنحك رابطاً حياً فوراً يمكنك إرساله للعميل.

### الطريقة الثانية: عبر GitHub & Vercel Dashboard:
1. ارفع الكود إلى مستودع جديد على حسابك في GitHub.
2. ادخل على [Vercel.com](https://vercel.com) واضغط **Add New Project**.
3. اختر المستودع، وسيقوم Vercel تلقائياً باكتشاف إعدادات Vite وتشغيل البناء.
4. مبروك! أصبح لديك رابط مباشر سريع ومحمي بشهادة SSL لعرضه على العميل.
